## Abstract

本研究では、ライブ会場の立地条件や周辺環境をGIS（地理空間情報システム）を用いて分析し、その結果をもとにライブ参加者向けのWebマップを作成することを目的とする。

ライブ参加者にとって重要となる交通アクセスや周辺施設などを地図上で可視化し、利用しやすい情報を提供するとともに、ライブ会場の立地特性について考察する。

# Introduction

## 研究背景

私自身音楽ライブが好きで、これまで様々なライブ会場を訪れてきた。しかし、初めて訪れる会場では、最寄駅やコインロッカー、トイレ、飲食店などの場所が分からず、その都度Google Mapsや公式サイトなど複数のサービスで検索する必要があり、不便さを感じてきた。

ライブ参加者の多くは遠征や初めて訪れる土地でライブに参加することも多く、私と同じような経験をしている人も少なくないと考えられる。

ライブ会場の場所はGoogle Mapsなどで確認できるが、ライブ参加者が必要とする情報は複数のサービスで個別に検索する必要がある。

ライブ参加者が必要とする情報をGISを用いて一つのWebマップ上に集約し、初めて訪れる会場でも安心して利用できる情報提供を目指す。これにより、情報収集にかかる負担を軽減し、ライブそのものをより楽しめる環境づくりに貢献したい。


そこで、本研究ではGISを活用してライブ参加者に必要な情報を一つにまとめたWebマップを作成し、その有用性について検討する。

## 研究目的

ライブ会場の立地条件や周辺環境をGISで可視化・分析し、その結果を反映したライブ会場情報Webマップを作成する。


## 先行研究

本研究に関連する先行研究として、ライブハウスを対象としたWebマップの作成や、イベント参加者への地理情報の提供に関する研究が挙げられる。

### 1. ライブハウスマップのデザイン

澤田浩二（2008）は、Google Maps APIを活用し、ライブハウス・ミュージシャン・ファンをつなぐWebマップ「LINDA」を構築した。

ライブハウスに関する情報を地図上で共有するという点で、本研究と関連している。

### 2. コミュニティ形成のためのマルチレイヤーマップ

澤田浩二・松村飛志・上野直樹（2007）は、ライブハウスコミュニティを対象に、Google Mapsを活用したマルチレイヤーマップのデザインについて研究した。

地図上で複数の情報を整理・可視化するという点で、本研究のWebマップ制作の参考となる。

### 3. リアルタイム曳山位置情報Webマップ

井上誠・伊藤優希菜（2024）は、祭事の理解や行動判断を支援するため、リアルタイムの曳山位置情報を提供するWebマップについて研究した。

ライブ会場を対象とした研究ではないが、イベント参加者の行動を地理情報によって支援するという点で、本研究と関連している。

詳細な文献情報は、GitHub Issue「参考文献」にまとめている。

## 本研究の新規性

先行研究では、ライブハウスに関する情報を地図上で共有するWebマップや、イベント参加者への位置情報の提供などが行われている。

これらに対して、本研究では全国9会場のZeppを対象とし、ライブ参加者が必要とする交通アクセスや周辺施設の情報を整理するだけでなく、GISを用いて各会場の立地条件や周辺環境を比較・分析することを目指す。

特に、コインロッカー、トイレ、コンビニ、飲食店など、ライブ参加当日に利用する可能性の高い施設に着目し、各会場を同一条件で比較する点に特徴がある。

また、分析結果をWebマップに反映することで、初めて訪れる会場でも必要な情報を効率的に確認できる仕組みを目指す。

このように、ライブ参加者向けの情報提供と、複数会場の立地比較を組み合わせることを本研究の特徴とする。

# Methods

## 研究対象

本研究では、日本全国のZeppライブハウス9会場を研究対象とする。

Zeppは全国に展開されるライブハウスブランドであり、同一ブランドの施設であることから、立地条件や周辺環境を比較しやすい。そのため、本研究では研究対象をZeppに限定し、ライブ参加者向けWebマップを作成する。

### 対象施設

- Zepp Sapporo（北海道）
- Zepp Haneda（TOKYO）
- Zepp DiverCity（TOKYO）
- Zepp Shinjuku（TOKYO）
- KT Zepp Yokohama（神奈川県）
- Zepp Nagoya（愛知県）
- Zepp Osaka Bayside（大阪府）
- Zepp Namba（OSAKA）
- Zepp Fukuoka（福岡県）

## 使用データ（予定）

### 会場情報
- ライブ会場（名称・位置情報）
- 最寄駅
- 駅から会場までの徒歩経路・徒歩時間

### 周辺施設
- コインロッカー
- トイレ
- コンビニ
- カフェ・飲食店


## 研究方法

本研究では、全国9会場のZeppを対象に、OSMデータの調査、周辺環境のGIS分析、Webマップの作成、有用性の評価を行う。

### 1. OSM登録状況の調査（実施済み）

OpenStreetMap（OSM）を使用し、全国9会場のZeppについて以下の項目を調査した。

- 会場の登録形式（ノード・ウェイ）
- 施設分類タグ（amenityなど）
- 建物情報や階層などの付加情報
- 会場ごとの登録状況の違い

調査結果を比較表にまとめ、OSMデータを利用する際の課題を整理した。

### 2. 周辺施設のデータ収集（今後実施）

OSMを中心に、各Zepp会場周辺の施設情報を収集する。

対象とする施設は以下のとおりである。

- コインロッカー
- トイレ
- コンビニ
- カフェ・飲食店
- 最寄駅

各会場を同一条件で比較できるように、調査範囲や施設の分類方法を検討する。

### 3. GISによる立地分析（今後実施）

収集した位置情報をもとに、GISを用いて各会場の立地条件や周辺環境を分析する。

分析項目として以下を検討している。

- 会場周辺の施設数
- 会場から周辺施設までの距離
- 最寄駅から会場までの距離や徒歩経路
- 会場ごとの周辺環境の違い

### 4. Webマップの作成（今後実施）

分析結果をもとに、全国9会場のZeppを対象としたWebマップを作成する。

ライブ参加者が会場や周辺施設の位置を一つの地図上で確認できるようにし、必要な情報を探しやすい構成を目指す。

### 5. Webマップの評価・改善（今後実施）

ライブ参加経験のある友人やゼミ生を対象に、作成したWebマップの使いやすさや有用性を評価する。

評価結果をもとに改善点を整理し、Webマップの改良につなげる。


## 研究スケジュール

- **8〜9月**：先行研究調査、研究対象・使用データの決定、データ収集
- **10〜11月**：GIS分析、Webマップ作成、中間発表
- **12〜1月**：Webマップ改善、アンケート、有用性の評価、論文執筆
- **2月**：最終発表

## 秋の中間発表時点での調査結果

## OSM登録状況の調査結果

### 調査概要

全国9か所のZeppを対象に、OpenStreetMap（OSM）上の登録状況を調査した。

各会場の登録形式（ノード・ウェイ）、施設分類タグ、付加情報を確認し、会場間の違いを整理した。


### OSMの基本用語

OpenStreetMap（OSM）では、地図上の施設や道路などを「ノード」「ウェイ」「リレーション」という形式で登録している。また、各データには「タグ」を付けることで、その場所がどのような施設なのかを示している。

| 用語 | 意味 | 今回の調査での例 |
|---|---|---|
| OpenStreetMap（OSM） | 誰でも地図情報を追加・編集できるオープンな地図データベース | 全国9会場のZeppの登録状況を調査 |
| ノード（Node） | 緯度・経度を持つ1つの点。施設の位置などを表す | Zepp Sapporoは点として登録 |
| ウェイ（Way） | 複数のノードをつないだ線。閉じた形にすることで建物の輪郭なども表せる | Zepp Osaka Baysideは建物の形状として登録 |
| リレーション（Relation） | 複数のノードやウェイなどをまとめて関係性を表すデータ | 複雑な建物や施設の構造などを表現できる |
| タグ（Tag） | 施設の種類や特徴を示す情報。「キー＝値」の形式で登録する | amenity=theatre |
| amenity=theatre | 劇場などの施設であることを示すタグ | Zepp DiverCityなど |
| amenity=music_venue | 音楽の演奏・公演を行う施設であることを示すタグ | Zepp Fukuoka |
| building=yes | 建物であることを示すタグ | Zepp Nagoya |
| building:levels | 建物の地上階数を示すタグ | Zepp Namba |
| level | 施設が位置する階層を示すタグ | Zepp DiverCity |
| website | 施設の公式サイトなどのURLを示すタグ | Zepp Sapporo |

### 登録形式の違い

今回の調査では、同じライブ会場でも登録形式に違いが見られた。

- **ノードの場合**：会場の位置を1つの点で表している。
- **ウェイの場合**：会場や建物の形状を表している。
- **ノードと建物ウェイがある場合**：会場の位置と建物の形状が別々のデータとして登録されている。

このように、同じ施設でもOSM上での表現方法が異なるため、データを収集する際には登録形式やタグの違いに注意する必要がある。


### 9会場の比較

| 会場 | 登録形式 | 主なタグ | 確認できた特徴 |
|---|---|---|---|
| Zepp Sapporo | ノード | amenity=theatre | 公式サイト・確認日が登録されている |
| Zepp Haneda | ノード＋建物ウェイ | amenity=theatre | 会場と建物が別々に登録されている |
| Zepp DiverCity | ウェイ | amenity=theatre | 階層・トイレ情報あり |
| Zepp Shinjuku | ノード | amenity=theatre | 商業施設内に位置する |
| KT Zepp Yokohama | ウェイ | amenity=theatre | 建物の一部として登録されている |
| Zepp Nagoya | 建物ウェイ | building=yes | 確認したウェイにはamenityタグがない |
| Zepp Osaka Bayside | ウェイ | amenity=theatre | 建物形状が登録されている |
| Zepp Namba | ウェイ | amenity=theatre | 建物階数が登録されている |
| Zepp Fukuoka | ノード | amenity=music_venue | 他会場と施設分類が異なる |

※2026年11月に確認したOSMデータをもとに作成。

### 調査から分かったこと

今回の調査では、同じZeppブランドであっても、OSM上の登録形式や施設分類、情報量に違いが見られた。

特に、Zepp Fukuokaでは他の多くの会場と異なる施設分類タグが使用されていた。また、Zepp Hanedaでは会場のノードと建物のウェイが別々に登録されていた。

このことから、今後9会場のデータを取得する際には、特定のタグや登録形式だけに限定せず、各会場のデータ構造を考慮する必要があると考えられる。

# Discussion

本研究では、GIS分析とWebマップの作成を組み合わせることで、ライブ参加者が初めて訪れるZepp会場でも必要な情報を効率的に取得できる環境を提供できると考える。

一方で、周辺施設をどの範囲まで対象とするかや、会場情報・周辺施設の詳細をどこまで掲載するかについては、今後検討する必要がある。また、データの取得方法やWebマップの有用性をどのように評価するかも課題である。

webマップの評価については、ゼミ生やライブ参加経験のある友人を対象にアンケートを実施し、改善点や有用性について評価したいと考えている。


## OSMデータの整備状況に関する考察

全国9会場の調査から、OSMのデータ整備状況には会場ごとに差があることが分かった。

特に、施設分類タグや登録形式が統一されていないことは、Webマップ制作におけるデータ取得上の課題となる。

また、OSMに情報が登録されていない場合でも、実際に施設や設備が存在しないとは限らない。そのため、公式サイトなどを活用した情報の確認・補完も必要である。

今後は、各会場の周辺施設を同一条件で収集し、施設数や距離などを比較することで、ライブ会場の立地特性を明らかにしていきたい。
