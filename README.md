## Abstract

本研究では、ライブ会場の立地条件や周辺環境をGIS（地理空間情報システム）を用いて分析し、その結果をもとにライブ参加者向けのWebマップを作成することを目的とする。

ライブ参加者にとって重要となる交通アクセスや周辺施設などを地図上で可視化し、利用しやすい情報を提供するとともに、ライブ会場の立地特性について考察する。

---

# Introduction

## 研究背景

私は音楽ライブが好きで、これまで様々なライブ会場を訪れてきた。その中で、ライブ会場によって交通アクセスや周辺施設、終演後の移動のしやすさなどが大きく異なることに気付いた。

現在、ライブ会場の場所はGoogle Mapsなどで確認できるが、ライブ参加者が知りたい情報（最寄駅からのアクセス、コインロッカー、飲食店、ホテルなど）は複数のサービスを行き来しながら調べる必要がある。

そこで、本研究ではGISを活用してライブ参加者に必要な情報を一つにまとめたWebマップを作成し、その有用性について検討する。

## 研究目的

ライブ会場の立地条件や周辺環境をGISで可視化・分析し、その結果を反映したライブ会場情報Webマップを作成する。

また、ライブ参加者にとって利用しやすいライブ会場にはどのような特徴があるのかを明らかにする。

---

# Methods

## 研究対象

全国のライブ会場を対象とする。

今後、以下のいずれかに対象を絞る予定である。

- Zepp
- アリーナ
- ドーム
- その他ライブ会場

## 使用データ（予定）

- ライブ会場
- 最寄駅
- 鉄道路線
- 徒歩時間
- コンビニ
- 飲食店
- ホテル
- コインロッカー
- その他ライブ参加時に必要な施設

## 研究方法

1. ライブ会場および周辺施設の位置情報を収集する。
2. GISを用いて会場周辺の環境を可視化・分析する。
3. 分析結果をもとにライブ参加者向けWebマップを作成する。
4. 必要に応じてライブ参加経験者へのアンケートを実施し、Webマップの有用性について評価する。

## 研究スケジュール

- **8〜9月**：先行研究調査、研究対象の決定、データ収集
- **10〜11月**：GIS分析、Webマップ試作、中間発表
- **12〜1月**：Webマップ改善、アンケート、考察、論文執筆
- **2月**：最終発表

# Results

本研究では以下の成果を目指す。

- ライブ参加者向けWebマップの公開
- ライブ会場の立地条件・周辺環境の可視化
- ライブ参加者が必要とする情報の整理
- GISを活用したライブ会場分析手法の提案

# Discussion

本研究では、GIS分析とWebマップの作成を組み合わせることで、ライブ参加者の情報収集を支援できる可能性があると考える。

一方で、研究対象をZeppなどのライブハウスに限定するか、アリーナやドームも含めるかについては今後検討が必要である。また、周辺施設データの取得方法や、Webマップの有用性をどのように評価するかも課題となる。

将来的には、情報を継続的に更新できる仕組みや、利用者が情報を追加・共有できる機能、ライブ遠征時のモデルルート提案などへ発展させることも検討したい。
