## Abstract

本研究では、ライブ会場の立地条件や周辺環境をGIS（地理空間情報システム）を用いて分析し、その結果をもとにライブ参加者向けのWebマップを作成することを目的とする。

ライブ参加者にとって重要となる交通アクセスや周辺施設などを地図上で可視化し、利用しやすい情報を提供するとともに、ライブ会場の立地特性について考察する。

---

# Introduction

## 研究背景

私は音楽ライブが好きで、これまで様々なライブ会場を訪れてきた。しかし、初めて訪れる会場では、最寄駅やコインロッカー、トイレ、飲食店などの場所が分からず、その都度Google Mapsや公式サイトなど複数のサービスで検索する必要があり、不便さを感じてきた。

ライブ参加者の多くは遠征や初めて訪れる土地でライブに参加することも多く、私と同じような経験をしている人も少なくないと考えられる。

現在、ライブ会場の場所はGoogle Mapsなどで確認できるが、ライブ参加者が知りたい情報（最寄駅からのアクセス、コインロッカー、飲食店など）は複数のサービスを行き来しながら調べる必要がある。

ライブ参加者が必要とする情報をGISを用いて一つのWebマップ上に集約し、初めて訪れる会場でも安心して利用できる情報提供を目指す。これにより、情報収集にかかる負担を軽減し、ライブそのものをより楽しめる環境づくりに貢献したい。


そこで、本研究ではGISを活用してライブ参加者に必要な情報を一つにまとめたWebマップを作成し、その有用性について検討する。

## 研究目的

ライブ会場の立地条件や周辺環境をGISで可視化・分析し、その結果を反映したライブ会場情報Webマップを作成する。

また、ライブ参加者にとって利用しやすいライブ会場にはどのような特徴があるのかを明らかにする。

---

# Methods

## 研究対象

本研究では、日本全国のZeppライブハウス9会場を研究対象とする。

Zeppは全国に展開されるライブハウスブランドであり、同一ブランドの施設であることから、立地条件や周辺環境を比較しやすい。そのため、本研究では研究対象をZeppに限定し、ライブ参加者向けWebマップを作成する。

### 対象施設

- Zepp Sapporo（北海道）
- Zepp Haneda（TOKYO）
- Zepp DiverCity（TOKYO）
- Zepp Shinjuku（TOKYO）
- KT Zepp Yokohama（神奈川県）
- Zepp Nagoya（愛知県）
- Zepp Osaka Bayside（大阪府）
- Zepp Namba（OSAKA）
- Zepp Fukuoka（福岡県）

## 使用データ（予定）

### 会場情報
- ライブ会場（名称・位置情報）
- 最寄駅
- 駅から会場までの徒歩経路・徒歩時間

### 周辺施設
- コインロッカー
- トイレ
- コンビニ
- カフェ・飲食店

## 研究方法

1. ライブ会場および周辺施設の位置情報を収集する。
2. GISを用いて会場周辺の環境を可視化・分析する。
3. 分析結果をもとにライブ参加者向けWebマップを作成する。
4. 必要に応じてライブ参加経験者へのアンケートを実施し、Webマップの有用性について評価する。

## 研究スケジュール

- **8〜9月**：先行研究調査、研究対象の決定、データ収集
- **10〜11月**：GIS分析、Webマップ試作、中間発表
- **12〜1月**：Webマップ改善、アンケート、考察、論文執筆
- **2月**：最終発表

# Discussion

本研究では、GIS分析とWebマップの作成を組み合わせることで、ライブ参加者が初めて訪れるZepp会場でも必要な情報を効率的に取得できる環境を提供できると考える。

一方で、周辺施設をどの範囲まで対象とするか（例：会場から半径500メートル圏内、800メートル圏内など）や、会場情報・周辺施設の詳細をどこまで掲載するかについては、今後検討する必要がある。また、データの取得方法やWebマップの有用性をどのように評価するかも課題である。

Webマップの評価については、まずはゼミ生やライブ参加経験のある友人を対象にアンケートを実施し、改善点や有用性について評価したいと考えている。
